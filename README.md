# Trip Fund Tracker

![Trip Fund Tracker](https://img.shields.io/badge/version-1.0.0-blue.svg) ![License](https://img.shields.io/badge/license-MIT-green.svg) ![Status](https://img.shields.io/badge/status-production-brightgreen.svg)

A personal finance application designed for single mothers saving for meaningful adventures with their children. Track savings goals, manage family contributions, and stay motivated with daily affirmations and financial wisdom.

**No accounts • No servers • 100% private • Single HTML file**

---

## 🌟 Highlights

- 🎯 **Personalized Greeting** — Time-dependent messages with your name
- 💰 **Financial Tracking** — Log income, track progress, analyze spending
- 👨‍👩‍👧‍👦 **Family Contributions** — Involve up to 5 children in saving
- 🗺️ **Trip Planning** — Plan destination, estimate costs, create wishlists
- 📊 **Visual Analytics** — Charts, trends, and detailed breakdowns
- 🧘‍♀️ **Motivation** — 32 affirmations + 18 financial wisdom principles with emoji icons
- 🔒 **Complete Privacy** — All data stays in your browser, no servers
- ⚡ **Zero Setup** — Download and open, start using immediately
- 📱 **Mobile Friendly** — Works on phones, tablets, and computers

## 💾 Data Storage & Privacy

### Where is My Data?
All data is stored in your browser's `localStorage`:
- Only accessible to you
- Persists across browser sessions
- Never sent to any server
- Cleared only when you choose to or clear browser data

### Backup & Transfer
Export your data as JSON anytime:
1. Go to **Settings** tab
2. Click "Export Data"
3. Save the JSON file to your computer
4. Import on another device or browser by uploading the file

### Complete Privacy Policy
✅ **No cloud storage** — Data never leaves your device
✅ **No accounts** — No personal information collected
✅ **No tracking** — No analytics or telemetry
✅ **No servers** — 100% client-side application
✅ **No ads** — Completely ad-free
✅ **No third parties** — No external services

## 🚀 Usage Guide

### Customize Your Greeting
1. Click **Settings** tab
2. Enter your name in the profile section
3. Click "Save Goal"
4. Your greeting updates immediately with your name
5. Greeting changes based on time of day (morning/afternoon/evening)

### Set Your Savings Goal
1. Click **Settings** tab
2. Enter your goal amount (e.g., $5,000 for a beach trip)
3. Click "Save Goal"
4. See your progress update in real-time on Dashboard

### Add Family Contributors
1. Go to **Trip Plan** tab
2. Click "Upload Photo" next to "You"
3. Click "+ Add Child" to add children (up to 5)
4. Upload a photo for each child
5. Each child appears in income tracking

### Log Your Income
1. Click "Log Income" button
2. Enter amount and select source:
   - Tips, Bonus, Freelance, Cashback, Gift
   - Lemonade Stand, Tag Sale, Facebook Marketplace, Chores
   - Other
3. Set the date and add notes
4. Click "Log Income"

### Log Child's Contribution
1. Click "Log Child's Contribution"
2. Select child from dropdown (or add new)
3. Enter amount and select source:
   - Chores, Allowance, Babysitting
   - Lemonade Stand, Tag Sale, Facebook Marketplace
   - Birthday Gift, Part-time Job, Other
4. Set date and notes
5. Click "Log Contribution"

### Plan Your Trip
1. Go to **Trip Plan** tab
2. Enter destination, dates, travelers
3. Upload banner image
4. Add destination photos to gallery
5. Use Trip Cost Estimator:
   - Enter origin and destination cities
   - Add flight costs
   - Enter nightly accommodation rate
   - Add daily activity and food budgets
   - See automatic total and per-day cost
6. Create activity wishlist

### Analyze Your Progress
1. Go to **Analytics** tab
2. View family contributions breakdown
3. See income by source
4. Check 12-month calendar
5. Analyze monthly patterns
6. Review year-to-date statistics

### Get Daily Motivation
1. Click **Affirmations** tab for inspiration with emoji icons
2. Click **Financial Wisdom** tab to learn principles
3. Use copy buttons to save favorites

## 🛠️ Technical Details

### Architecture
- **Single Page Application** — All code in one HTML file
- **No Dependencies** — Pure HTML, CSS, and JavaScript
- **Chart.js** — For visualizations (included via CDN)
- **localStorage API** — For data persistence

### Data Format
All data stored as JSON in browser localStorage:
```javascript
{
  userName: string,
  goalAmount: number,
  income: [{ amount, source, date, notes }],
  childIncome: [{ amount, source, childName, date }],
  children: [{ id, name, age, avatar }],
  photos: [{ id, data (base64) }],
  // ... more data
}
```

### Performance
- Loads instantly (single HTML file)
- No network requests (except Chart.js from CDN)
- Fast data access from localStorage
- Responsive animations and transitions

## ❓ FAQ

### Where is my data stored?
All data is stored in your browser's `localStorage`. Nothing is sent to any server.

### Can I use on multiple devices?
Yes! Export your data on one device, import on another. Go to Settings → Export Data.

### Is it safe?
Yes. No personal information is collected. All processing happens in your browser.

### What if I clear my browser data?
Your app data will be deleted. Always keep backups using Export Data.

### Can I share my data?
Yes. Export as JSON and share the file, or import on another device/browser.

### Do I need an account?
No. The app requires no registration, login, or personal information.

### Why no cloud sync?
To protect your privacy. We don't store your financial data on servers.

### Can I add more than 5 children?
Currently limited to 5. Let us know if you need more!

### Is there a mobile app?
Currently web-based only. Mobile app planned for future version.

### How do I customize my greeting?
Go to Settings, enter your name, and click "Save Goal". Your greeting updates with your name and changes based on time of day.

### How do I get help?
[Open an issue](https://github.com/yourusername/trip_tracker/issues) on GitHub with your question.
